## David's setup checklist (one time)

1. Create a private GitHub repo and clone it to the Windows machine.
2. Copy this starter kit into the repo root and commit it.
3. Install Unity Hub, then Unity 6 LTS with the Android Build Support
   module (include the SDK, NDK, and OpenJDK options).
4. Create a new Unity project in the repo folder using the Universal 3D
   (URP) template.
5. Add a Unity .gitignore before the first commit of the project.
6. Enable Developer Options and USB debugging on an Android phone.
7. Open Claude Code in the repo folder and send the kickoff message from
   README.md.
